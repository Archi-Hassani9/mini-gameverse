# Mini GameVerse 🎮

**Mini GameVerse** is a neon-themed mini gaming website built using ReactJS. It includes multiple interactive games with live score tracking.

## 🚀 Features

* **Simulated Login Authentication:** A sleek, styled gateway to access the main platform.
* **Interactive Games Library:**
  * **Number Guessing:** Test your luck and logic.
  * **Rock Paper Scissors:** The classic hand game.
  * **Tic Tac Toe:** Play the timeless X and O strategy game.
  * **Memory Card Flip:** Match pairs of cards while racing against a timer.
* **Live Scoreboard:** Persistently tracks wins, losses, attempts, and best times across all games in a dedicated dashboard.

## 🛠️ Technologies Used

* **Frontend:** ReactJS, JavaScript, CSS, HTML
* **State Management:** React Hooks (`useState`, `useEffect`)

## 💻 Getting Started

To run this project locally on your machine:

1. **Clone the repository:**
    git clone [https://github.com/Archi-Hassani9/mini-gameverse.git](https://github.com/Archi-Hassani9/mini-gameverse.git)
2. **Navigate to the project directory:**
    cd mini-gameverse
3. **Install dependencies:**
    npm install
4. **Start the development server:**
    npm start
5. **Open http://localhost:3000 to view it in the browser.**
